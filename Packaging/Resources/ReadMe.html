安装说明

版本：@VERSION@。最低系统版本：macOS @MINIMUM_OS@。

安装与升级

安装位置为 /Applications/右键助手.app，需要管理员授权。升级前请退出正在运行的右键助手；安装程序会替换旧应用，用户设置和自定义模板保存在用户资源库中。

签名状态

本版应用使用本地 ad-hoc 签名，安装包未使用 Developer ID Installer 签名，也未经过 Apple 公证。首次下载打开时，macOS 可能提示无法验证开发者。请先核对项目的 GitHub 发布来源和 SHA-256 校验信息，再按照系统“隐私与安全性”的提示处理。

首次使用

安装后从“应用程序”打开右键助手。在“通用设置”中打开 Finder 扩展设置，并启用“右键助手”。
