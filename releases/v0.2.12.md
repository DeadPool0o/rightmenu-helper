# 右键助手 v0.2.12

本版补齐安装后的 Finder 扩展启用引导，帮助定位“安装后右键只有 ChatGPT 一项”的情况。

## 更新内容

- 首次打开且扩展未启用时，显示说明并提供“打开 Finder 扩展设置”按钮。
- 安装完成后在当前用户的桌面自动打开应用，主动呈现启用引导。
- 通用设置显示 Finder 扩展的启用状态，从系统设置返回后自动刷新。
- 安装向导和文档明确说明：安装应用后还需启用系统的 Finder 扩展开关。
- 增加“只有 ChatGPT 服务”和“已启用但未显示菜单”的排查步骤。
- 安装时检测已有版本：旧版提示覆盖升级，同版本允许修复安装，更新版本阻止降级；保留用户设置和自定义模板。

## 下载与安装

支持 **macOS 13 及以上版本**。Universal 安装包同时支持 Apple 芯片（arm64）和 Intel（x86_64）。

| 下载文件 | 用途 |
| --- | --- |
| `RightClickAssistant-0.2.12-macos-universal.pkg` | 推荐，双击运行安装程序 |
| `RightClickAssistant-0.2.12-macos-universal.zip` | 解压后将应用放入“应用程序” |
| `SHA256SUMS.txt` | SHA-256 下载校验值 |
| `release-info.json` | 版本、架构、源码提交及签名状态 |

安装结束后会自动打开右键助手，按弹窗引导进入 Finder 扩展设置并启用“右键助手”。没有登录桌面或系统阻止启动时，请从“应用程序”手动打开。升级前请退出旧版应用，用户配置和自定义模板保留。

“用 ChatGPT 打开（右键助手）”由系统服务提供，其余右键功能由 Finder 扩展提供。出现 ChatGPT 一项不能说明 Finder 扩展已经启用。若已启用仍未显示菜单，请关闭再开启该扩展并重新打开访达窗口。

**签名状态：应用使用 ad-hoc 本地签名，安装包未使用 Developer ID Installer 签名，未经过 Apple 公证。** 首次下载打开可能需要在“隐私与安全性”中允许该安装包或应用。[Apple 官方说明](https://support.apple.com/102445)
