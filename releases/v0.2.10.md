# 右键助手 v0.2.10

本版补齐系统应用图标，并首次提供 macOS 安装程序与便携版下载。设置页保留现有蓝底白色光标标识。

## 更新内容

- 补齐应用包图标，供 Finder、系统搜索等位置显示。
- 提供带中文欢迎页、安装说明及完成提示的 `.pkg` 安装程序，安装到“应用程序”。
- 同一安装包同时包含 Apple 芯片和 Intel 版本，无需选择架构。
- 附带便携版 ZIP、SHA-256 校验值及构建元数据。
- 增加标签触发的自动构建、校验和 GitHub Release 发布流程。
- 打包和解包验证在临时目录中执行，完成后自动清理，避免验证副本重复出现在系统应用搜索中。

## 功能

- 新建 TXT、Markdown、RTF、XML、Word、Excel、PowerPoint、JSON、HTML、Python、Swift 等文件，并支持自定义模板。
- 配置模板名称、排序、启用状态和右键主菜单位置。
- 文件复制、移动、常用目录、进入终端、发送文件到应用等右键操作。
- 系统文件图标预设、自选图片图标及恢复默认图标。

## 下载与安装

**仅支持 macOS 13 及以上版本。** Universal 安装包同时支持 Apple 芯片（arm64）与 Intel（x86_64）。

在下方 **Assets** 中下载：

| 下载文件 | 说明 |
| --- | --- |
| `RightClickAssistant-0.2.10-macos-universal.pkg` | 推荐，双击运行 macOS 安装程序 |
| `RightClickAssistant-0.2.10-macos-universal.zip` | 解压后将应用放入“应用程序” |
| `SHA256SUMS.txt` | SHA-256 文件校验值 |
| `release-info.json` | 版本、架构、源码提交及签名信息 |

安装完成后打开“右键助手”，进入“通用设置”，打开 Finder 扩展设置并启用“右键助手”。使用安装包无需安装 Python 或 Xcode。

**签名状态：应用为 ad-hoc 本地签名，安装包未使用 Developer ID Installer 签名，未经过 Apple 公证。** macOS 可能阻止首次打开；确认 GitHub 发布来源后，按“系统设置 → 隐私与安全性”中的“仍要打开”提示操作。安装包和应用可能分别触发检查。参见 [Apple 官方说明](https://support.apple.com/102445)。

升级前请退出旧版应用。安装程序会更新“应用程序”中的应用，用户设置和自定义模板保留。

## 验证与限制

- 功能自动检查与 Office 模板容器完整性检查通过。
- 应用和 Finder 扩展均包含 arm64、x86_64 可执行代码。
- 打包时解包检查 PKG 与 ZIP 中的应用签名、架构、图标、模板及安装路径。
- 本机运行验证环境为 Apple 芯片 Mac；尚未在实体 Intel Mac 和 macOS 13 上执行完整安装回归。
