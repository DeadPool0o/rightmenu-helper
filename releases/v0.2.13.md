# 右键助手 v0.2.13

将固定的 ChatGPT 入口改为通用“打开方式”，可以添加自己常用的本机应用，并保存到右键子菜单。

## 更新内容

- 新增“打开方式”设置页，可搜索本机已安装的应用，支持多选添加、逐项启用或停用、删除。
- 读取系统、当前用户的应用目录及其分类子目录，显示应用图标、名称和安装位置；其他位置可手动浏览添加。
- 已添加的应用持久保存在右键“打开方式”子菜单，旧版工具箱中保存的应用会保留。
- 支持右键文件或文件夹后选择“添加应用并打开…”，完成首次打开并保存快捷项。
- 移除“用 ChatGPT 打开”和“让 ChatGPT 分析…”专用入口；系统服务改为“打开方式（右键助手）”。
- 豆包、WorkBuddy 等 AI 软件和其他软件均可按需添加。通过 macOS 文件打开接口传递所选项目，实际支持的文件类型和文件夹由目标应用决定，不自动传入分析提示词。
- 已停用或移除的应用不能通过旧菜单继续执行；应用已移动或卸载时会提示重新添加。

## 下载与安装

支持 **macOS 13 及以上版本**。Universal 安装包同时支持 Apple 芯片（arm64）和 Intel（x86_64）。

| 下载文件 | 用途 |
| --- | --- |
| `RightClickAssistant-0.2.13-macos-universal.pkg` | 推荐，双击运行安装程序 |
| `RightClickAssistant-0.2.13-macos-universal.zip` | 解压后将应用放入“应用程序” |
| `SHA256SUMS.txt` | SHA-256 下载校验值 |
| `release-info.json` | 版本、架构、源码提交及签名状态 |

升级前请退出旧版应用，安装程序会在原位置更新，保留用户设置和自定义模板。安装后进入“打开方式 → 添加本机应用…”选择需要的程序。

首次安装仍需在系统设置中启用“右键助手”的 Finder 扩展。“打开方式（右键助手）”属于系统服务，不能代表完整 Finder 右键菜单已启用。

应用使用 ad-hoc 本地签名，安装包未使用 Developer ID Installer 签名，未经 Apple 公证。首次打开的操作及菜单排查参见[安装说明](https://github.com/DeadPool0o/rightmenu-helper/blob/main/INSTALL.md)。
